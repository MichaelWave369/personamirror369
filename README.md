# PersonaMirror369

**A humane atlas for the masks we wear.**

PersonaMirror369 is a consent-based research, reflection, and interactive software project for mapping the everyday masks people wear, understanding the social pressures that create them, and helping individuals and communities reduce unhealthy pretending without shame, coercion, exposure, or manipulation.

> We do not rip masks off people.  
> We help people feel safe enough to set them down.

## Core Idea

People wear masks every day. Some masks are protective, useful, and temporary. Others become rigid, fear-driven, and identity-fused. PersonaMirror369 treats a mask not as a lie, but as an adaptive interface between the inner self and the social world.

The project introduces the **Pretending Force Engine**: a framework for modeling the pressures that push people away from truthful coherence and into performance, suppression, conformity, or false certainty.

## Ethical Boundary

This project is not for controlling people, exposing people, diagnosing people, or manipulating society.

PersonaMirror369 is designed for:

- self-reflection
- social literacy
- anti-manipulation education
- humane AI companion design
- family and community repair
- workplace honesty tools
- truth-safety mapping
- consent-based personal growth

It is not designed for:

- coercive persuasion
- surveillance
- psychological profiling without consent
- workplace punishment systems
- social scoring
- forced disclosure
- diagnosis or therapy replacement

## Project Modules

| Module | Purpose |
|---|---|
| Mask Atlas | Taxonomy of common social masks |
| Pretending Force Engine | Formula system for social/persona pressure |
| Mask Load Model | Measures intensity, frequency, rigidity, truth-distance, and duration |
| Coherence Delta | Maps distance between private truth and public performance |
| Frontstage / Backstage Map | Reflection tool for different social settings |
| Safe Truth Planner | Helps choose gentle, non-coercive truth actions |
| Group Pretending Simulator | Models how false norms spread through silence and fear |
| Anti-Manipulation Mode | Helps users detect when others are pressuring them into a mask |

## Formula Seeds

### Pretending Force

```txt
PF = (SR + BR + PR + FR + AR + ER) - (TS + SC + PC + RC)
```

Where:

```txt
PF = Pretending Force
SR = Shame Risk
BR = Belonging Risk
PR = Punishment Risk
FR = Financial / survival Risk
AR = Approval Reward
ER = Ego Reward
TS = Truth Safety
SC = Self-Compassion
PC = Private Coherence
RC = Repair Capacity
```

### Mask Load

```txt
ML(m) = I × F × R × D × T
```

Where:

```txt
ML = Mask Load
I  = Intensity
F  = Frequency
R  = Rigidity
D  = Distance from inner truth
T  = Time worn
```

### Core Distinction

```txt
Protective Mask = conscious + temporary + useful + removable
Prison Mask     = unconscious + chronic + fear-based + identity-fused
```
