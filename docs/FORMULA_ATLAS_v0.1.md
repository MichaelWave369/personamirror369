# PersonaMirror369 Formula Atlas v0.1

## 1. Pretending Force

```txt
PF = (SR + BR + PR + FR + AR + ER) - (TS + SC + PC + RC)
```

### Variables

| Symbol | Name | Meaning |
|---|---|---|
| PF | Pretending Force | Pressure pushing a person away from private truth and into performance |
| SR | Shame Risk | Expected shame if truth is expressed |
| BR | Belonging Risk | Expected loss of belonging if truth is expressed |
| PR | Punishment Risk | Expected punishment, retaliation, or consequence |
| FR | Financial / Survival Risk | Expected survival cost of truth |
| AR | Approval Reward | Social/status reward gained by performing the mask |
| ER | Ego Reward | Identity reward gained by keeping the mask |
| TS | Truth Safety | Safety available for honest expression |
| SC | Self-Compassion | Internal mercy available when truth appears |
| PC | Private Coherence | Alignment with inner truth |
| RC | Repair Capacity | Availability of repair, apology, boundary, or reconciliation paths |

### Interpretation

High PF means the environment may punish truth or reward performance. Low PF means truth is more available.

## 2. Mask Load

```txt
ML(m) = I × F × R × D × T
```

### Variables

| Symbol | Name | Meaning |
|---|---|---|
| ML | Mask Load | Weight of a specific mask |
| I | Intensity | How strongly the mask takes over |
| F | Frequency | How often the mask appears |
| R | Rigidity | How hard it is to remove or soften |
| D | Truth Distance | Distance between mask and inner truth |
| T | Time Worn | Duration spent in the mask |

### Interpretation

Mask Load is not moral judgment. It estimates how much energy a mask is carrying.

## 3. Coherence Delta

```txt
CD = |PT - PP|
```

Where:

```txt
CD = Coherence Delta
PT = Private Truth
PP = Public Performance
```

High CD may indicate strain, conflict, or role pressure. The goal is not forced disclosure. The goal is safer truth.

## 4. Truth Safety Index

```txt
TSI = (Consent + Mercy + Privacy + Repair + NonPunishment) / 5
```

The Truth Safety Index estimates whether truth can emerge without disproportionate harm.

## 5. Mask Release Potential

```txt
MRP = (TS + SC + RC + Support + Timing) - (SR + PR + FR)
```

High Mask Release Potential means the user may be able to gently soften the mask. Low MRP suggests pause, preparation, or support.

## 6. Group Pretending Field

```txt
GPF = Σ(PFᵢ × Visibilityᵢ × Imitationᵢ × Punishmentᵢ) / TrustDensity
```

The Group Pretending Field models how false norms, silence spirals, or public performance can spread through groups.

## 7. Mask Integrity Law

```txt
Healthy Mask = Conscious + Chosen + Temporary + Removable + Value-Aligned
```

## 8. Prison Mask Law

```txt
Prison Mask = Unconscious + Chronic + Fear-Based + Rigid + Identity-Fused
```

## 9. Mercy Gate

Before any mask interpretation, pass the Mercy Gate:

```txt
Can this reflection be offered without shame, coercion, exposure, or identity trapping?
```

If no, do not output the interpretation.

## 10. Closing Formula

```txt
Truth + Mercy + Safety + Repair = Mask Release
```
