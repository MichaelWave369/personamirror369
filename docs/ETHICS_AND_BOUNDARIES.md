# Ethics and Boundaries

PersonaMirror369 is a consent-based reflection and education framework. Its purpose is to help people understand masks, social pressure, and pretending force without shame, coercion, surveillance, diagnosis, or manipulation.

## Prime Directive

```txt
We do not rip masks off people.
We help people feel safe enough to set them down.
```

## What This Project Is

PersonaMirror369 is:

- a reflection tool
- a social literacy framework
- an anti-manipulation education project
- a humane software design pattern
- a paper/research scaffold
- a vocabulary for self-awareness and group-pressure analysis

## What This Project Is Not

PersonaMirror369 is not:

- a clinical diagnostic tool
- therapy or medical treatment
- a social scoring system
- an employee monitoring system
- a deception detector
- a coercive persuasion framework
- a tool for exposing people without consent
- a tool for controlling society

## Consent Rules

1. The user must choose to engage.
2. The user must be free to stop.
3. The user must not be forced to disclose private truths.
4. Reflections should remain local-first/private wherever possible.
5. Outputs should avoid labels that trap people in identities.
6. The system should recommend safe support when distress, danger, or abuse is present.

## Language Rules

Use language that is:

- invitational
- non-diagnostic
- non-shaming
- humble
- compassionate
- clear about uncertainty

Avoid language that is:

- accusatory
- mind-reading
- deterministic
- humiliating
- coercive
- purity-based
- superiority-based

## Safe Output Pattern

Preferred:

```txt
This may suggest a Pleaser Mask is active. It might be protecting belonging or reducing conflict. Consider asking: Where am I saying yes because I am afraid to be loved less?
```

Avoid:

```txt
You are fake. You are a people-pleaser. Stop lying.
```

## High-Risk Use Cases to Reject

PersonaMirror369 should not be used to:

- screen job applicants
- rank employees by authenticity
- detect romantic partner deception
- pressure someone into confession
- build persuasion funnels
- exploit emotional vulnerability
- identify dissidents or nonconformists
- punish people for social masking

## Claim Discipline

PersonaMirror369 may use inspiration from psychology, sociology, philosophy, systems thinking, and symbolic design. It must not overclaim.

Use these claim labels:

| Label | Meaning |
|---|---|
| EXACT | Directly implemented in software or directly stated in project docs |
| VALID UNDER ASSUMPTION | Works if the stated assumptions are accepted |
| EMPIRICAL HYPOTHESIS | Needs real-world testing |
| ARCHITECTURAL MAPPING | Useful as design metaphor or software structure |
| NON-CLAIM | Symbolic, poetic, or creative framing only |

## Closing Rule

A mask often began as protection. Treat it with respect before asking it to change.
